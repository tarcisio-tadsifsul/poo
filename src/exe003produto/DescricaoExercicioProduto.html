1. Crie um objeto para representar um Produto de uma loja. 2. Este objeto deve possuir os atributos: - nome - preco - quantidadeEstoque Todos definidos como privados. 3. A classe deve implementar métodos de acesso (get/set) para todos os atributos. 4. No método de atribuição do preço, não deve ser permitido aceitar valores negativos ou zero. 5. Além disso, crie métodos para - adicionarEstoque(int qtd) - removerEstoque(int qtd) Garantir que a remoção não resulte em um estoque negativo. 6. Na classe principal, utilize o teclado para cadastrar 3 produtos em um vetor 7. Realize simulações de vendas e reposição de estoque, exibindo o estado final de cada objeto.
