Componentes do Método

Modificador de Acesso: Define quem pode usar o método (ex: public, private, protected). O modificador public permite acesso de qualquer outra classe.

Tipo de Retorno: Define o tipo de dado que o método devolve. Se o método não devolve nada, usa-se a palavra-chave void.

Nome do Método: Deve seguir o padrão camelCase (ex: calcularSoma).

Parâmetros: Variáveis locais que recebem valores quando o método é chamado. Ficam entre parênteses e são separados por vírgulas.

Corpo do Método: Bloco de código delimitado por chaves {} que contém a lógica a ser executada.

Comando return: Usado para enviar o valor de volta para quem chamou o método. É obrigatório para qualquer tipo diferente de void
