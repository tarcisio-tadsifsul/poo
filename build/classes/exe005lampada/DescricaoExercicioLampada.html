Crie uma classe para representar uma lâmpada. Desenvolva métodos para ligar e desligar a lâmpada. Inclua também um método para modificar a cor da lâmpada, recebendo o novo valor por parâmetro, sendo que este valor deve ser validado a partir de um vetor de cores possíveis que a lâmpada aceita ser configurada. Outro método que retorne a cor atual da lâmpada. plique encapsulamento para todos atributos da classe, disponibilizando acessos de leitura e escrita conforme necessário.
