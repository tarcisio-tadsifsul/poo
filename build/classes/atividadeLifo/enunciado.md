[✓] Implemente uma estrutura de dados do tipo Pilha em Java.

[✓] Utilize como dado um objeto que você deve criar, contendo alguns atributos devidamente encapsulados.
A estrutura deve conter obrigatoriamente:
    [✓] Métodos de inserção e remoção, respeitando a política LIFO apresentada em aula
    [✓] Método para imprimir, que deve retornar uma string da estrutura de dados
    [✓] Método para redimensionar a estrutura, tornando-a dinâmica sempre que necessário
    [✓] Método para ver a quantidade de elementos que há na pilha
    [✓] Método para ver a capacidade máxima de elementos que a pilha suporta
    [✓] Método para evitar duplicidade de elementos na mesma pilha
    [✓] Método para verificar se um dado elemento está ou não na estrutura

[✓] Teste a implementação no método principal, a partir de um menu interativo (console) que permite consumir todas as opções disponíveis da estrutura de dados, garantindo que a opção de encerrar o programa invoque o Garbage Collector explicitamente.

Siga as convenções de código, nomenclatura e sintaxe padrão da linguagem Java.
